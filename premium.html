TOPIC 2.4

Thevenin's Theorem

Any linear bilateral network containing sources and resistances can be replaced, as viewed from two terminals, by a single equivalent voltage source VTH in series with an equivalent resistance RTH.

Statement

The theorem simplifies a complicated network into a two-terminal equivalent circuit. It is particularly useful when the load changes repeatedly while the rest of the network remains unchanged.

Procedure

  1. Remove the load resistance from the network.
  2. Find the open-circuit voltage across the terminals.
  3. Deactivate independent sources and calculate RTH.
  4. Reconnect the load to the Thevenin equivalent.
